# Big Crew Roles

Big Crew is a reusable agentic engineering crew.

Its first real mission is to help build Maliwan 2.0 from Maliwan 1.0 context.

Each crew role has a specific responsibility so the project does not jump directly from idea to code.

## Crew Flow

1. Product Strategist clarifies value and scope.
2. System Architect defines technical boundaries and trade-offs.
3. QA Sentinel defines acceptance criteria and regression tests.
4. Prompt Smith creates a Codex-ready implementation prompt.
5. Release Captain checks readiness, release safety, and Definition of Done.

## First Mission

Build Maliwan 2.0 as a household-aware care orchestrator.

Maliwan 2.0 should support:

- multi-household structure
- household-aware sessions
- member-scoped medication
- household-scoped inventory
- future family admin editing
- SQL-backed data layer
- regression-tested vertical slices
