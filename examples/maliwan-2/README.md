# Curated Big Crew Examples

This folder preserves selected generated Big Crew work packages as portfolio examples.

`output/engineering-work-package.md` remains the scratch/latest generated output file.
It is expected to change whenever Big Crew runs and should usually not be committed.

The files in this folder are intentionally curated examples that show how Big Crew behaves across milestones.

Why these examples matter:
- They show the input brief that was used.
- They show the generated engineering work package.
- They show the decision-based Crew Role Trace.
- They make role judgment, boundary enforcement, test thinking, and release readiness visible.

Recommended journey:
1. Read the input brief in `inputs/maliwan-2/`.
2. Generate a work package with Big Crew.
3. Copy the generated output into `examples/maliwan-2/`.
4. Review the package and record the evaluation in `reviews/maliwan-2/`.
5. Use the reviewed package as implementation input in `maliwan-2`.

Suggested curated examples:
- `001-repo-bootstrap-work-package.md`
- `002-d1-schema-validation-work-package.md`
- `003-medication-repository-contract-work-package.md`

These examples are enough to show the early Maliwan 2.0 journey:
- repo bootstrap
- D1 schema validation
- medication repository contract

You can add later examples when new milestones are worth preserving.
