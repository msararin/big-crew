# Maliwan 1.0 Known Limitations

- Google Sheets is becoming hard to extend.
- Multi-household support is not designed yet.
- Session boundaries are not mature enough.
- Medication data should be member-scoped.
- Inventory data should be household-scoped.
- Family admin editing is not yet designed.
- Direct editing in Google Sheets is risky for long-term use.
- The current architecture came from MVP speed and may still have mixed responsibilities.
- Maliwan 2.0 should avoid copying Maliwan 1.0 runtime code directly.
- Future work should use small vertical slices and regression tests before broad refactoring.
